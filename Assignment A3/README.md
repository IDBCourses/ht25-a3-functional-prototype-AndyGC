Basic game loop:

    1. Balloons will spawn on top of pumps.
    2. If corresponding key is NOT pressed, balloon will deflate.
    3. If corresponding key IS pressed, balloon will inflate.
    4. If a balloon becomes too small the player loses a life. Too big and it pops, also losing a life.
    5. Clicking a pump below a balloon will release the balloon assuming it's above the minimum size value to be released.
    6. Player can release all viable balloons at once by pressing spacebar, on a 5 second cooldown timer.
    7. Balloons will deflate faster and respawn more frequently over time.
    8. There is currently no win condition, only a game over on losing 3 lives, the game resets automatically.

Controls:

Left-click: Release (on pump)
Q: Left pump
W: Middle pump
E: Right pump
Space: Release all
